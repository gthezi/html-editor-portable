# HTML Editor Portable

Windows 本地 HTML 可视化编辑工具。基于 [deckflow/html-editor](https://github.com/deckflow/html-editor)，提供双击启动、桌面快捷方式和资源管理器右键入口。

## 如何安装

适用于 Windows 10/11 x64，需要可访问 Node.js 下载站和 npm 仓库。无需预装 Node.js，也无需管理员权限。

1. 登录 GitHub 。
2. 点击 **Code > Download ZIP**，把压缩包完整解压到一个固定目录；不要在压缩包内直接运行。
3. 双击根目录的 `Setup.cmd`。首次运行会下载便携 Node.js、安装锁定的编辑器依赖、应用本地修复，并建立桌面快捷方式和右键菜单。
4. 通过桌面的 **HTML Editor** 打开工具，或者右键任意 `.html` 文件，选择 **使用 HTML Editor 编辑**。

也可以通过 GitHub CLI 下载：

```powershell
gh auth login
gh repo clone gthezi/html-editor-portable
cd html-editor-portable
.\Setup.cmd
```

第一次安装需要联网。已有运行时和依赖会被复用。

## 日常使用

- 默认服务地址：<http://127.0.0.1:4177>，只绑定本机，不对外提供网络服务。
- 打开单个 HTML 或项目目录后，改动自动保存到原文件；看到 `Saved` 才表示保存成功。
- 保存前备份位于所编辑项目的 `.local-html-editor/backups/`，不在这个工具仓库中。
- 移动安装目录后，重新运行 `Setup.cmd` 更新快捷方式和右键菜单。
- `Uninstall.cmd` 删除快捷方式和右键入口，不删除工具文件或所编辑的文档。

## Reviewable HTML

编辑器工具栏中的 **Review copy** 会下载一个独立的 `*.review.html` 审阅副本，不覆盖原始 HTML。把这个副本发给其他人后，对方不需要安装 HTML Editor，用 Chrome 或 Edge 打开即可：

- 选择正文中的文字并添加批注、高亮和可选的修改建议；
- 右侧批注面板可用顶部的批注按钮或面板关闭按钮收起；收起后只保留小按钮，已写入的批注和输入草稿不会丢失，点击按钮可重新打开；
- 在右上角批注面板查看、定位、编辑、解决或删除批注；
- 在批注输入区选择黄、蓝、粉三种颜色；前三位不同作者默认优先使用不同颜色。同一姓名保持颜色对应，更换颜色会同时更新该作者已有批注；超过三位作者时会复用颜色。
- 选择文字后，即使在面板中输入批注，正文范围仍持续高亮；点击已保存批注的原文引用，会强调对应文字。窄屏面板优先放在选区上方或下方。
- 点击批注面板的下载按钮，导出带有当前批注及作者颜色映射的 `*.reviewed.html` 文件；
- 把导出的审阅文件发回给原作者。

批注运行时内嵌在审阅副本中，不依赖服务器或外部 JavaScript。原始正文不会被审阅者直接修改；批注锚点使用选中文本及前后文定位，无法唯一匹配时会保守地提示原文已变化。浏览器本地缓存只用于临时恢复，不替代审阅文件导出。

审阅副本的文件名通常是 `报告.review.html`，导出后的结果通常是 `报告.reviewed.html`。批注版适合异步文件交换；多人实时协作需要后续增加服务端存储，不属于当前版本。


## 本地修复

`scripts/patch-local.js` 在安装后自动应用本地改进：

1. 隐藏文件选择器的控制台窗口，并使文件、文件夹选择窗口在前台置顶显示；窗口只在选择期间提升，不修改 Windows 全局焦点设置。
2. 修复删除或复制组件、修改子元素后使用过期元素定位的问题，避免自动保存失败或重复文字兄弟节点被误删。
3. 添加可批注 HTML 副本导出，内嵌批注颜色及持续选区高亮。
4. 添加页面内安全停止服务按钮，并在后台退出时清理属于自身的 PID 记录。
5. 预览缩放测量保留当前输入节点的编辑属性，避免窗口尺寸变化导致编辑会话提前结束。

已导出的审阅 HTML 内含导出时的组件版本，不会自动更新。升级旧副本时，先在旧文件中导出审阅结果以保留浏览器里的最新批注，再把该结果导入编辑器并点击 **Review copy**。重新生成会保留文件内已保存的批注、文档标识和作者颜色映射，并替换组件；不会读取其他浏览器中未导出的草稿。

编辑器依赖固定为 `@deckflow/html-editor@0.1.8`。补丁保存在仓库里，依赖安装目录无需提交。浏览器中已经打开的旧编辑器页面需要刷新才能加载更新；刷新前请记录尚未保存的改动。

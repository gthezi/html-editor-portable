HTML Editor

这是默认起始页。编辑器已经可以正常使用，接下来把你自己页面打开即可。

打开你自己的 HTML

  1. 点击窗口右上角的 Open project。
  2. 选择 HTML file 打开单个页面，或选择 Project folder 打开整个项目目录。
  3. 打开单个文件时，编辑器会自动把它所在目录设为项目根，从而保留相对路径的图片、CSS、JS。

编辑与保存

  • 点击文字即可直接修改；拖动元素可以移动位置；选中后可拖手柄调整尺寸。
  • 改动会自动保存回原文件（无需手动保存）。
  • 每次保存前，编辑器都会在项目目录下的 .local-html-editor/backups/ 留一份备份。
提示：本页只是占位说明，可以随意删改。要打开别的项目时，重复使用 Open project 即可， 不必重启程序。
